Informed sampling techniques focus sampling on the set of states whose heuristic cost is below the cost of the current solution. Initial solutions are often tortuous, which keeps this region large. Abstract

Informed sampling techniques accelerate the convergence of sampling-based motion planners by biasing sampling toward regions of the state space that are most likely to yield better solutions. However, when the current solution path contains redundant or tortuous segments, the resulting informed subset may remain unnecessarily large, slowing convergence. Our prior work addressed this issue by introducing the greedy informed set, which reduces the sampling region based on the maximum heuristic cost along the current solution path. In this article, we formally characterize the behavior of the greedy informed set within Rapidly-exploring Random Tree (RRT*)-like planners and analyze how greedy sampling affects exploration and asymptotic optimality. We then present Greedy RRT* (G-RRT*), a bi-directional anytime variant of RRT* that leverages the greedy informed set to focus sampling in the most promising regions of the search space. Experiments on abstract planning benchmarks, manipulation tasks from the MotionBenchMaker dataset, and a dual-arm Barrett WAM problem demonstrate that G-RRT* rapidly finds initial solutions and converges asymptotically to optimal paths, outperforming state-of-the-art sampling-based planners.

Greedy informed sampling

The heuristic cost f^(x)\hat f(\mathbf{x})f^​(x) of a state is a lower bound on the cost of any path from the start through that state to the goal. No path through the state can have a lower cost. Under the Euclidean metric, it is the sum of the straight-line distances from the start to the state and from the state to the goal, and the states whose heuristic cost is below a given value form a prolate hyperspheroid. Informed sampling samples from the set of states whose heuristic cost is at most the cost of the current solution [1]. The greedy informed set lowers this bound to the maximum heuristic cost along the current solution path [2].

When the current solution is in the same homotopy class as the optimal path, the greedy informed set contains the optimal path (Theorem 1 of the paper). Two paths with the same endpoints are in the same homotopy class when one can be continuously deformed into the other without crossing an obstacle. When the two paths are in different homotopy classes, the greedy informed set might not include the optimal path, as in the Slalom scene above (Remark 1 of the paper). For this reason, G-RRT* also samples from the informed set to preserve asymptotic optimality.

Greedy sampling in high dimensions

For fixed path costs, the volume of the greedy informed set relative to the informed set decreases exponentially with the dimension of the state space. When the greedy informed set contains every state that can improve the current solution, G-RRT* needs fewer samples than informed sampling to find a better solution. The expected number of samples decreases by a factor of about 0.9 divided by this volume ratio (Theorem 3 of the paper). Greedy sampling therefore helps most in high dimensions.

G-RRT*

G-RRT* grows one tree from the start and one from the goal. As in RRT-Connect [3], it connects the two trees greedily, so it finds an initial solution quickly. After the trees meet, G-RRT* rewires both trees as RRT* [4] does. It samples each new state from the greedy informed set with probability ϵ\epsilonϵ, the greedy biasing ratio, and from the informed set otherwise. Any ϵ<1\epsilon < 1ϵ<1 keeps asymptotic optimality, and we use ϵ=0.9\epsilon = 0.9ϵ=0.9.

MotionBenchMaker on four robots

MotionBenchMaker [6] generates realistic manipulation problems for common robots, in scenes such as bookshelves, tables, boxes and cages. We solve them with G-RRT* in VAMP for the Panda, UR5, Fetch and the dual-arm Baxter, which have 6 to 14 degrees of freedom (DoF). For a typical problem in each scene, the viewer replays the initial solution and the best solution found within the time budget, each before and after simplification.

Results

VAMP on MotionBenchMaker

We compare G-RRT* with RRT-Connect [3], AORRTC [7] and FCIT* [8] on the MotionBenchMaker problems of all four robots. AORRTC simplifies each solution before it reports it, so we compare final solution costs after simplification. After simplification, the median final solution costs of G-RRT* and AORRTC are within 0.3% of each other on the Panda and UR5 and within 1% on the Baxter, and G-RRT* has a 4% lower median final solution cost on the Fetch.

We also run G-RRT* with ϵ=0\epsilon = 0ϵ=0, so that it samples only from the informed set. Both versions find the same initial solution, but the ϵ=0\epsilon = 0ϵ=0 version converges more slowly on all four robots. The difference is largest on the Fetch and Baxter, where the greedy informed set is smallest relative to the informed set.

OMPL experiments from the paper

The paper's experiments in OMPL [9] compare G-RRT* with eight other planners, on abstract problems in up to 16 dimensions, on MotionBenchMaker problems for the Panda and Fetch, and on a dual-arm Barrett WAM problem with 14 DoF. G-RRT* finds initial solutions at least as fast as RRT-Connect and converges faster than the other asymptotically optimal planners. Without path simplification, its final solution costs are comparable to those of AORRTC, whose reported costs already include simplification. After simplification, G-RRT* has the lowest median final solution cost on 13 of the 15 problems.
